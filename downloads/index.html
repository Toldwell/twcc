Stream Deck and Companion

Drive Tiles from a Stream Deck or Bitfocus Companion: settings, REC, Playback, the app's lock and every other control, on keys and dials lit by what each camera says.

First, in Tiles: Settings → Control API → turn it on, and copy the token. The iPad, iPhone or Mac running Tiles and the computer running Stream Deck or Companion need to be on the same network, and Tiles in the foreground.

Stream Deck

Tiles-StreamDeck-2.2.1.streamDeckPlugin (plugin 2.2.1, Stream Deck 6.6 or later on a Mac, macOS 13 or later). Double-click it and Stream Deck installs it. Then drag a Tiles key onto a page and enter the address of the device running Tiles and its token.

Companion

Tiles-Companion-0.3.1.tgz (module 0.3.1, Companion 4.1 or later). In Companion: Modules → Import module package → choose the file. Then add a Tiles connection with the device's address and the token, and use its presets.
